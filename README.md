# 💼 Developer Portfolio – Shubham Dhapola

A visually appealing and fully responsive **Portfolio Website** built using **React**, designed to showcase my projects, technical skills, and personal journey as a developer. The site emphasizes a modern UI/UX experience and clean design aesthetics across all devices.

## 🚀 Features

- 🎯 **Built with React**, JavaScript, and CSS3 with a focus on component-based structure and maintainability.
- 🎨 **Creative and modern UI design** that highlights both personal branding and project work.
- 📷 **Project showcase** implemented using `react-slick` slider for smooth, responsive carousels.
- 🔗 **Smooth-scroll navigation** for a seamless browsing experience.
- 📨 **Contact form** integration with getform.io, including proper validation and spam protection.
- 📱 Fully **responsive layout** optimized for mobile, tablet, and desktop.

## 🛠️ Tech Stack

- **React.js** – Frontend framework  
- **CSS3** – Styling and responsive layout  
- **JavaScript** – Logic and interactivity  
- **Axios** – For future-ready API interactions  
- **react-slick** – Project carousel  
- **smooth-scroll** – Smooth navigation  
- **getform.io** – Form submission handling
